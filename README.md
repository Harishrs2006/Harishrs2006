## About

I design and ship production software for real markets — from database schema to app in someone's hand. Right now I'm running **[Sthiva](https://sthiva.com)**, a live B2B construction materials marketplace in Karnataka, and contributing to cloud-native projects across the CNCF ecosystem.

- **Founder & sole engineer** on Sthiva — 3 mobile apps, 3 web portals, 1 TypeScript API, live in Karnataka
- **CNCF contributor** — merged fixes in Microcks, Meshery, Chaos Mesh, Reshapr, and more
- **Stack** — TypeScript, React Native, Next.js, Node.js, Flutter, Python, Go, Java
- 2nd year B.Tech CSE · Polaris School of Technology · Bengaluru
